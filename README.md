# namifufu blog - お金と投資の情報サイト

30代女性の視点でお金・投資・資産運用について分かりやすく解説する投資情報ブログです。

## 📖 概要

このプロジェクトは、投資初心者の方向けに、お金と投資に関する実用的な情報を分かりやすく発信するブログサイトです。NISA制度の活用方法から不動産投資クラウドファンディングまで、幅広い投資情報を30代女性の目線で解説しています。

## 🎯 主な特徴

- **初心者目線**: 投資初心者でも理解しやすい丁寧な解説
- **実践的な内容**: 実際の口座開設手順や投資体験に基づいた情報
- **レスポンシブ対応**: PC・タブレット・スマートフォンすべてに対応
- **カテゴリー別整理**: NISAとクラウドファンディングの2つのメインカテゴリーで構成

## 🔧 カスタマイズ

### 新しい記事の追加
`js/category-script.js`の`articleData`オブジェクトに新しい記事情報を追加することで、簡単に記事を増やすことができます。

### カテゴリーの追加
新しいカテゴリーを追加する場合は、以下の手順で行います：
1. `articleData`に新しいカテゴリーオブジェクトを追加
2. ナビゲーションメニューにリンクを追加
3. 必要に応じて新しいHTMLページを作成

### デザインの変更
`css/home-style.css`のCSS変数やスタイル定義を調整することで、サイトの外観をカスタマイズできます。

### 画像の管理
記事の画像は外部URL（GenSparkサイト）でホストされており、`articleData`内の`image`プロパティで管理されています。
