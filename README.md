# SBI証券口座開設ガイド

SBI証券の口座開設手順を分かりやすく解説したWebサイトです。

## 📖 概要

このプロジェクトは、SBI証券での投資を始めたい初心者の方向けに、口座開設から初期設定までの全手順を画像付きで詳しく説明するガイドサイトです。

## 🎯 主な特徴

- **分かりやすい構成**: 準備→申し込み→設定の順で段階的に説明
- **視覚的なデザイン**: カラフルで見やすいステップバイステップガイド
- **レスポンシブ対応**: PC・タブレット・スマートフォンすべてに対応
- **実用的な内容**: 実際の申し込み手順に基づいた正確な情報

## 📋 構成内容

1. **タイトル**: 「【動画と画像で分かる】SBI証券のはじめ方！」
2. **日付**: 2024年11月22日公開
3. **注意喚起**: 操作前に確認すべき重要事項
4. **記事の目的**: 最短10分で申し込み完了できることを説明
5. **操作手順の詳細説明**:
   - 準備するもの（本人確認書類、銀行口座情報、連絡先）
   - 口座開設の3ステップ
   - 初期設定の4ステップ
6. **まとめ**: 口座開設の重要性とポイントの再確認

## 🛠️ 技術仕様

- **HTML5**: セマンティックなマークアップ
- **CSS3**: Flexbox/Gridレイアウト、アニメーション
- **JavaScript**: スムーススクロール、インタラクティブ機能
- **フォント**: Noto Sans JP（日本語Webフォント）
- **レスポンシブデザイン**: モバイルファーストアプローチ

## 💡 主な機能

1. **スムーススクロール**: 目次リンクからの滑らかな画面遷移
2. **ステップアニメーション**: スクロール時のフェードインアニメーション
3. **アクティブナビゲーション**: 現在表示中のセクションをハイライト
4. **トップへ戻るボタン**: スクロール位置に応じて表示/非表示
5. **レスポンシブレイアウト**: デバイスサイズに応じた最適化

## 🔧 カスタマイズ

### 画像の追加
`images/`フォルダに画像を配置し、HTMLの`.image-placeholder`部分を実際の画像タグに置き換えてください。

### デザインの変更
`css/style.css`のカラー変数やフォントサイズを調整することで、サイトの外観をカスタマイズできます。

### 機能の拡張
`js/script.js`に追加の JavaScript 機能を実装できます。フォームバリデーション、プログレスバー、読書進捗保存などの基本機能が準備されています。
